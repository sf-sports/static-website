# SF Sports — Launching Soon

A lightweight static launch page for [sfsports.in](https://sfsports.in).

## Preview locally

Open `index.html` directly in a browser, or serve the folder with any static file server.

## GitHub Pages

The included `CNAME` file configures the custom domain as `sfsports.in`. In the repository settings, enable GitHub Pages from the `main` branch and configure the required DNS records with your domain provider.
